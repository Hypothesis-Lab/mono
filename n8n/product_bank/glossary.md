# Глоссарий Lumen

| Термин | Значение |
|---|---|
| Lumen банк | Бренд, к карте которого подключается описанный кредитный лимит |
| Lumen | Карта, совмещающая дебетовую и кредитную части |
| Дебетовая карта | Карта для операций за счёт собственных средств клиента |
| Зарплатная карта | Дебетовая карта, используемая в зарплатном сценарии |
| Кредитный лимит | Максимальная сумма заёмных средств, предоставленная банком |
| Желаемый лимит | Сумма от 30 000 до 100 000 ₽, которую клиент указывает в заявлении |
| Предоставленный лимит | Сумма, которую банк фактически одобрил и подключил |
| Доступный лимит | Часть предоставленного лимита, не использованная клиентом и доступная сейчас |
| Собственные средства | Деньги клиента на счетах, привязанных к карте |
| Заёмные средства | Сумма, использованная из подключённого кредитного лимита |
| Задолженность | Сумма обязательств клиента по использованным кредитным средствам |
| Расчётный период | Период, по итогам которого определяется обязательный платёж |
| Обязательный платёж | Минимальная сумма погашения: 5% основного долга, но не менее 300 ₽ |
| Полное погашение | Погашение всей задолженности, а не только обязательного платежа |
| Беспроцентный период | До 55 дней при своевременных обязательных платежах и полном погашении долга |
| Заявление | Запрос клиента на подключение кредитного лимита |
| Рассмотрение | Проверка заявления до принятия решения банком |
| Одобрение | Положительное решение банка по заявлению или лимиту |
| Отказ | Решение не подключать лимит или не предоставить заявленную сумму |
| Настройка лимита | Действия клиента в приложении после принятия решения |
| Привязанная карта | Дебетовая или зарплатная карта, к которой подключается лимит |
| Предварительная проверка | Сопоставление с заданными правилами до решения банка |
| Кредитное решение | Итоговое решение банка по заявлению клиента |
| Канал коммуникации | Способ доставки предложения: приложение, push, email, landing или SMS |
| Действующий держатель карты | Клиент с дебетовой или зарплатной картой Lumen банка |
| Идентификатор заявления | Уникальный номер заявки для отслеживания статуса |

## Нельзя смешивать

- Желаемый лимит не равен предоставленному.
- Предварительная проверка не равна одобрению.
- Одобрение не равно подключению, если клиент ещё не принял условия.
- Кредитный лимит не равен собственному остатку.
- Обязательный платёж не равен полному погашению.
- 55 дней не означают безусловное отсутствие переплаты.
- Наличие карты не означает согласие на рекламные сообщения.
- Отправленное заявление не означает, что деньги уже доступны.
