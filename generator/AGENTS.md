# Generator

The `collab/` folder contains reference files. Treat its contents as documentation only.

After making code changes, first run `task format`, then run `task lint`, and fix all reported issues.

All functions should be below classes in files.

Handlers must define their own request and response structures and explicitly
map service results into those structures. A handler must not return a service
object or service result directly.
