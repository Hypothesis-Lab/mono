# Глоссарий Tempo

Термины и определения, используемые в интерфейсе и документации Tempo.

| Термин | Значение в материалах Tempo |
|---|---|
| Точка | Отдельное кафе или кофейня в аккаунте компании |
| Смена | Запланированный рабочий период с началом, окончанием, ролью, точкой и назначенным сотрудником |
| Расписание / график смен | Набор смен на выбранный период |
| Черновик | Расписание или смена, которые ещё не опубликованы сотрудникам |
| Публикация расписания | Действие управляющего, после которого расписание становится видимым сотрудникам |
| Доступность | Указанные сотрудником периоды, когда он может работать; не гарантия назначения |
| Запрос на выходной | Запрос сотрудника, который ожидает решения управляющего |
| Запрос на обмен сменами | Предложение обменять две смены; обмен вступает в силу после одобрения управляющего |
| Открытая смена | В терминологии отрасли смена без назначенного сотрудника; функция открытых смен в Tempo не описана и не обещана |
| Прогноз спроса | Оценка будущей потребности в персонале по ожидаемой нагрузке; Tempo такую функцию не предоставляет |
| Фактическое время | Реально отработанное время, зафиксированное учётом прихода/ухода; Tempo его не фиксирует |
| Потребность в персонале | Количество сотрудников, нужных для покрытия работы; Tempo не рассчитывает его автоматически |

## Полезное различие

«Расписание опубликовано» не равно «сотрудник подтвердил смену». «Запрос отправлен» не равно «изменение одобрено». «Доступен» не равно «назначен».
